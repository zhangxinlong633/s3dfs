# 基准

| | |
| --- | --- |
| 读者 | 需要复现或引用本机数字的人 |
| 机器 | 同一台 MacBook Pro（Apple M5 Pro，15 核，48 GB，Apple SSD AP1024Z），Bun 1.4.2 |
| 范围 | 2026-11-21 及更早是单机 localhost。N=3 是同一台机器上的三个 block 进程，不是多机网络。2026-11-22 起是三台虚拟机上的测试集群 |
| 效力 | 选型时的形状说明，不是容量承诺。换一套机器要重测，不要把两次 ops/s 相减 |

每次测量单独放在 [benchmarks](benchmarks/) 里，按日期一篇。对象大小和副本数看最近的那篇。更早的日期不要和它的 ops/s 相减。

| 日期 | 内容 |
| --- | --- |
| [2026-11-23](benchmarks/2026-11-23.md) | 16 核 API 按网络、块、索引、响应四段分开。同日补了 1 KiB 与 1 MiB 的读和写 |
| [2026-11-22](benchmarks/2026-11-22.md) | 三台测试机，3 副本。晚上补了 `RECID_v1` 页，以及一块盘同时写 8 或 16 个 `.blk` 的不压缩写入 |
| [2026-11-21](benchmarks/2026-11-21.md) | 四档大小；以及与 11 月 17 日同一协议的全量，含压缩 |
| [2026-11-17](benchmarks/2026-11-17.md) | 全量：并发、压缩、进程内编解码、磁盘布局 |
| [2026-11-16](benchmarks/2026-11-16.md) | 旧代码：还没有 `recId`，以及 block 上还有本地 LevelDB |
