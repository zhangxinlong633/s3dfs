# 基准

| | |
| --- | --- |
| 读者 | 需要复现或引用本机数字的人 |
| 机器 | 同一台 MacBook Pro（Apple M5 Pro，15 核，48 GB，Apple SSD AP1024Z），Bun 1.4.2 |
| 范围 | 单机 localhost。N=3 是同一台机器上的三个 block 进程，不是多机网络 |
| 效力 | 选型时的形状说明，不是容量承诺。上线容量以目标集群的测量为准 |

每次测量单独放在 [benchmarks](benchmarks/) 里，按日期一篇。对象大小和副本数看最近的那篇。更早的日期不要和它的 ops/s 相减。
